# Noventra POS - Standalone Windows Installation & Deployment Guide

This guide describes how to set up and run **Noventra POS** as a 100% offline, standalone desktop application on a Windows laptop with **Oracle Database 21c Express Edition (XE)**.

---

## 1. Important Pre-Check: Oracle 11g XE Incompatibility

> [!CAUTION]
> **If Oracle Database 11g XE is already installed on this computer, it MUST BE COMPLETELY UNINSTALLED first.**
>
> 1. Oracle 11g XE and Oracle 21c XE **cannot coexist** on the same machine (they conflict on TCP port 1521, listener registrations, and Windows registry hives).
> 2. Noventra POS uses modern SQL syntax, identity columns, and pluggable database architecture that **are NOT supported by Oracle 11g**.
>
> **How to uninstall Oracle 11g XE before proceeding:**
> 1. Open Windows **Control Panel > Programs and Features**.
> 2. Select **Oracle Database 11g Express Edition** and click **Uninstall**.
> 3. Restart the laptop when prompted.
> 4. Ensure `C:\oraclexe` or previous Oracle 11g directories are deleted before installing 21c.

---

## 2. Install Oracle Database 21c Express Edition (XE)

1. Download **Oracle Database 21c Express Edition for Windows x64** (`OracleXE212_Win64.zip`) from Oracle's official site.
2. Extract the ZIP file and run `setup.exe` as Administrator.
3. When prompted, specify a password for the `SYS`, `SYSTEM`, and `PDBADMIN` administrative accounts (e.g., `Manager123` or your chosen secure password). Keep this password safe.
4. Complete the installation.
5. Verify that the Windows service **`OracleServiceXE`** and the listener **`OracleOraDB21Home1TNSListener`** are installed and running:
   - Press `Win + R`, type `services.msc`, and press Enter.
   - Confirm **OracleServiceXE** has status **Running** and Startup type **Automatic**.
   - Confirm **OracleOraDB21Home1TNSListener** is **Running**.

---

## 3. Configure Pluggable Database (XEPDB1) & Create App User

Noventra POS connects to the pluggable database **`XEPDB1`**.

1. Open **Command Prompt** or **PowerShell** as Administrator.
2. Connect to Oracle as SYSDBA:
   ```cmd
   sqlplus / as sysdba
   ```
3. Switch session container to `XEPDB1` and create the application database user `isi`:
   ```sql
   ALTER SESSION SET CONTAINER = XEPDB1;

   -- Create application user (replace 'YourPasswordHere' with your secure password)
   CREATE USER isi IDENTIFIED BY YourPasswordHere;

   -- Grant permissions required for POS operations and sequences
   GRANT CONNECT, RESOURCE, DBA TO isi;

   -- Allocate unlimited quota on USERS tablespace
   ALTER USER isi DEFAULT TABLESPACE USERS QUOTA UNLIMITED ON USERS;

   -- Exit SQL*Plus
   EXIT;
   ```

## 4. Application Directory & Configuration Setup

Noventra POS keeps code and mutable data completely decoupled:
- **Application Directory:** `C:\NoventraPOS\app\` (the extracted PyInstaller `--onedir` bundle containing `NoventraPOS.exe`).
- **Data Directory:** `C:\NoventraPOS\data\` (auto-created by `NoventraPOS.exe`).

### Step-by-Step Configuration:

1. Extract the Noventra POS distribution bundle into `C:\NoventraPOS\app\`.
2. Open PowerShell or Command Prompt in `C:\NoventraPOS\app\`.
3. Run the setup switch to initialize directories:
   ```cmd
   NoventraPOS.exe --setup-shortcuts
   ```
   This automatically creates:
   - `C:\NoventraPOS\data\`
   - `C:\NoventraPOS\data\uploads\` (with `items`, `logos`, and `temp`)
   - `C:\NoventraPOS\data\logs\`
   - `C:\NoventraPOS\data\backups\`
   - `C:\NoventraPOS\data\.env` (with a freshly generated cryptographic `SECRET_KEY`)
   - Desktop and Windows Startup shortcuts.

4. Open `C:\NoventraPOS\data\.env` in Notepad:
   ```cmd
   notepad C:\NoventraPOS\data\.env
   ```
5. Set `DB_PASSWORD` to the password you created for user `isi` in Step 3:
   ```ini
   FLASK_ENV=production
   SECRET_KEY=<auto-generated-hex-key>

   # Oracle Database Configuration (Oracle XE 21c)
   DB_HOST=127.0.0.1
   DB_PORT=1521
   DB_SERVICE_NAME=XEPDB1
   DB_USER=isi
   DB_PASSWORD=YourPasswordHere
   DB_SCHEMA=ISI

   TERMINAL_CODE=T01
   COUNTER_CODE=C01
   ```
6. Save and close Notepad.

## 5. Pre-Flight Check & Database Initialization

Run the explicit CLI switches from `C:\NoventraPOS\app\`:

### Step 5.1: Test Oracle Connectivity
```cmd
NoventraPOS.exe --db-check
```
*Expected Output:*
- Connection to `127.0.0.1:1521/XEPDB1`: **OK**
- Character Set: **AL32UTF8**
- Permissions: **OK**

### Step 5.2: Execute Database Migrations
> Migrations never run automatically on application launch.
```cmd
NoventraPOS.exe --migrate
```
*Process:*
1. Automatically takes a pre-migration safety backup into `C:\NoventraPOS\data\backups\`.
2. Applies all Alembic migration revisions up to head.

### Step 5.3: Create Super Admin Account
```cmd
NoventraPOS.exe --create-admin
```
*Prompts:*
- Username: `admin` (or desired username)
- Password: [secure password]
- Confirm Password: [secure password]

## 6. Daily Operation

1. **Launch the POS:**
   - Double-click the **Noventra POS** icon on the Windows Desktop, OR
   - Launch `C:\NoventraPOS\app\NoventraPOS.exe`.
2. **Automatic Browser Launch:**
   - Waitress starts on `http://127.0.0.1:5000/`.
   - The default browser opens immediately to the POS login screen.
3. **Single Instance Protection:**
   - Launching the app again will not start duplicate servers; it simply activates the running instance in the browser.
4. **Daily Backups & USB Mirroring:**
   - The daily backup executes automatically in a non-blocking background thread on first launch each day.
   - In **Settings > General**, specify a USB Drive letter (e.g. `E:`). When plugged in, backups will automatically mirror to `<USB>:\NoventraPOS_Backups\`.
   - The Dashboard shows backup status (`Today`, `X days ago`, or `Failed` in red if an issue occurs).

## 7. Troubleshooting & Recovery

| Issue | Resolution |
| :--- | :--- |
| **ORA-12541: TNS:no listener** | Ensure Windows service `OracleOraDB21Home1TNSListener` is Running in `services.msc`. |
| **ORA-12514: TNS:listener does not currently know of service** | Confirm database `XEPDB1` is open: run `sqlplus / as sysdba` then `ALTER PLUGGABLE DATABASE XEPDB1 OPEN;`. |
| **App fails to start / blank window** | Check logs in `C:\NoventraPOS\data\logs\noventra_pos.log`. |
| **Manual immediate backup** | Run `NoventraPOS.exe --backup`. |
